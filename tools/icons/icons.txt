# LUI icon set. Regenerate with:
#   python tools/icons/build_icons.py
#
# lucide <out_name> <lucide_icon> [filled] [zoom=N] [sized]
#   Rendered from tools/icons/lucide/icons/<lucide_icon>.svg in both line
#   weights: assets/ui/icons/<out_name>_thin_64.tga (stroke 2) and
#   <out_name>_bold_64.tga (stroke 2.5). zoom=N crops the canvas around its
#   centre (small glyphs fill their slot) and keeps the rendered line weight.
#   sized also writes <out_name>_<weight>_<N>.tga for every pre-scaled size
#   (build_icons.py SIZED): the game draws those unstretched, so they clip
#   inside scrolling lists.
#
# own <out_name> <source> [sized]
#   Shape (alpha) taken from a single-colour TGA under tools/icons/sources/:
#   assets/ui/icons/<out_name>_64.tga (sized: also <out_name>_<N>.tga).
#
# Every output is white; the colour comes from the in-game tint.
